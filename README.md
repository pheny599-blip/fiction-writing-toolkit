# Fiction Writing Toolkit

**小说创作工具包｜基于 AI Skills 的小说创作与一致性管理工作流**

一套面向长篇小说创作者的可复用 AI Skill 与工作流集合。

本项目尝试解决 AI 辅助小说创作过程中常见的问题：设定遗忘、人物行为失真、剧情逻辑冲突、文风不统一，以及长篇创作缺乏连续性。

## ✨ 核心功能

| Skill | 功能 |
|---|---|
| `fiction-canon` | 管理世界观、人物关系、能力规则和设定边界 |
| `fiction-outline` | 规划故事大纲、剧情因果及伏笔 |
| `fiction-scene-audit` | 检查场景中的人物、动作及逻辑一致性 |
| `fiction-voice-revision` | 根据作者原有文风进行文本修订 |
| `fiction-chapter-closeout` | 完成章节检查、状态更新及后续写作衔接 |

## 📦 项目组成

项目包括：

- 5 个可复用的小说创作 Skill
- 2 条创作工作流
- 3 个辅助程序
- 配套模板、使用说明和测试文件

## 🚀 如何开始

📖 [查看完整安装教程与 Skill 使用说明](fiction-writing-skills/README.md)
1. 下载或克隆本仓库。
2. 阅读项目目录中的使用说明。
3. 根据需要选择对应的 Skill。
4. 按照 Skill 的具体说明，在兼容的 AI 编程或 Agent 环境中配置使用。
5. 结合自己的小说设定与创作目标调整工作流。

不同 AI 平台对 Skill 的加载方式可能不同，具体安装方式请以项目内的文档为准。

## 💡 设计理念

AI 不应该取代作者的创作判断，而应该帮助作者管理复杂的信息与逻辑。

本项目希望将小说创作中可以标准化、重复执行的工作拆分为独立模块，让作者将精力集中在人物塑造、叙事设计与文学表达上。
