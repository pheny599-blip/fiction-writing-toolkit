# 交付与恢复契约

任务ID / 分支 / 批准大纲及确认来源 / 候选稿精确版本 / 实际报告与审查身份 / 来源版本与变化 / R0及已用返修轮数 / 未闭问题 / 作者接受状态与范围。

固定稿路径 / 候选与固定稿哈希是否一致 / 实际章末状态及逐项正文位置 / 未结束动作与后果 / 下一章输入清单 / 唯一编辑者或无 / 最近交接 / 下一步。

恢复：读进度与最后完整交接 → 确认旧编辑者停止 → 对照输入版本和文件完整性 → 标明未完成/失效文件 → 在新版本恢复相应阶段。不得把出现文件当作阶段完成。

机器契约由可选工具文档另行说明；缺少程序不影响手工执行本Skill。章末状态与正文必须分开保存。
