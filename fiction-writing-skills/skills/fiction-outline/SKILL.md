# 因果大纲

## 输入

采用前文/结尾、有效设定、相关人物完整小节、关系阶段与知情、作者目标、必须保留结果及禁止揭露。缺章号或分支先查可用材料，仍有歧义则提出必要问题。用 [大纲模板](references/template.md)。

## 执行

1. 从前章未结束动作、伤势、资源、关系余波确定起点。只选真正改变事件的人；群像可拆场，不固定统一人数或高光配额。
2. 每个推进步骤说明人物想要什么、何种刺激/障碍迫使选择、为什么不能简单离开、选择怎样造成下一变化。环境和物件在需要时承担帮助、阻挡、暴露与留痕。
3. 将允许揭露的信息逐项绑定知情者、渠道与时点；区分作者已知和角色能推断，高潮不能靠未获准能力或突然精确知情解决。
4. 按起因、经过（开端/发展/关键峰值/余波）、结果讲清完整故事。日常章可用关系或认知变化形成峰值，不强加战斗、突破或整齐段数。
5. 标明必须保留的结果、可替换的场面细节、待确认核心设定。示例动作和台词不应固化为逐句配方。收尾留下具体未决事项，不擅自承诺下一章事件。
6. 交作者确认明确版本；沉默和等待不构成同意。关键结果、动机、设定或揭露范围改变后重新确认受影响部分；一般句段小修不反复申请大纲批准。

## 输出与异常

输出读得通的大纲和简短边界/确认项，不混入长检查卡、不写未经批准的整章正文。依据矛盾时列出处和影响，无法成立的因果不要以“随后/恰好”遮过。见 [使用示例](references/example.md)。
