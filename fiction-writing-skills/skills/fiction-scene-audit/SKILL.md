# 场景集中审查

## 输入与权限

指定稿件版本、相关原始规则、人物完整小节、关系与能力条目、前文结尾/状态、批准大纲及本轮变更。先确认范围和实际审查身份。默认只输出报告，不改全文。用 [审查契约](references/template.md)。

## 执行

1. 划分场景，发言者、地点、冲突目标或情绪阶段明显变化时重新调用完整人物依据及作者叙述规范。对每个发言者列欲求、不愿承认之事、对象关系、身体情绪、已知渠道与可能误判。只行动者查动作依据。
2. 沿连续互动检查：当前刺激 → 想怎样影响对方 → 说出与保留什么 → 对方实际反应。声音看思路和互动，不凭“嗯/谢谢”共享句或口癖判同声；不强迫误解、争吵或自动达成共识。
3. 分开认识、信任、秘密知情与担责；后台背景不等于视角人物知情，未来关系不等于已建立。能力对照发动、范围、代价、失败和当前掌握，不以炫目描写补新效果。
4. 在动作转换点核对站位、姿态、左右手占用、物件归属、距离、时间、伤势与空间。台词中的“起来/松手”等须有前态；只把读者理解需要的信息写入修订要求，不要求正文逐句报坐标。
5. 旁白核对视角权限、判断证据、动作后果、环境作用及作者风格选择。审对白过度解释、同构推理、填空动作与笑点结算要举连续上下文，不以禁词、句长、语气词比例或AI百分比裁决。
6. 问题分阻断（规则/知情/关键因果不可能）、必要修改（有证据的持续阅读或人物问题）、可选建议（审美分歧）。给ID、位置原文、依据、影响、修复归属与复审条件。局部成立的互动先保留，结构失效才升级重写。
7. 修订后保留问题ID，核对受影响的全章事实和新问题；R0首次审查，默认最多R1—R3返修复审，仍未通过交作者裁定，不暗中重置计数。

## 输出与异常

报告列读取覆盖、版本、身份、问题和结论。缺必要原文、读取截断或核心矛盾未解写无法完成/需返修，不能写通过。区分本轮必需来源缺失与本轮未要求的检查：例如独立新场景没有前章，或只查事实并未要求匹配稳定文风，须说明不适用的范围，不能扩大通过结论。全部阻断和必要修改关闭且适用覆盖完成才可通过；自检不等于独立审查。见 [示例](references/example.md)。
