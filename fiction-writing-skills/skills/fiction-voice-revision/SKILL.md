# 依据文风的局部修订

## 输入

指定稿件与可改范围、作者本轮目标、经授权使用的作者样本/风格规范、相关人物完整小节和必须保留的事实。没有样本时可按本轮要求小修，明确无法声称匹配既定文风。用 [对照模板](references/template.md)。

## 执行

1. 从样本提取会改变修订决定的特征：视角距离、信息组织、动作与判断关系、节奏、对白社交方式、情绪呈现和收尾。区分稳定倾向、特定场景和作者明确硬要求；不要把样本每句结构变成禁令。
2. 先列本段已经成立的互动与必须保留内容，再定位需要改变的表达。人物目的或事件因果失效时给证据退结构修订，不通过删解释掩盖漏洞。
3. 只改授权句段；重新调用涉及发言者的完整人物依据与场景叙述规范。语气词、连接、沉默、长短句按此人此刻的社交目的选择，不能全删或机械补齐。
4. 对照：不将猜测变事实、试探变断言、浅识变密友、热络变同意；能力效果/代价、知情渠道、事件顺序和揭露时点保持有效。动作已能表达时是否再解释，取决于作者目标和语境，不强迫所有作者采用一种旁白。
5. 局部修改后回读相邻动作、物件和连续对白，撤回引入的新矛盾。新版本单独保存；关键结果或设定改变先按项目授权确认。风格偏好不应伪装为事实阻断。

## 输出与异常

纯正文与修改记录分开，列改动位置、理由、依据和事实保真核对；不要输出作者样本大段复制、检测百分比或“已去除AI味”保证。仅提供建议时不要声称改了文件。参见 [示例](references/example.md)。
