# 维护与迭代

版本：0.1.0候选。每次改动说明来源问题、影响的Skill/契约及实际检查。先修实际失败，不为增加技能数量拆模块。

发布时人工维护release-allowlist.json的具体文件名，逐一审查内容。运行校验、测试、独立语义演练与私人源重复扫描；构建只含白名单的独立目录。复核哈希清单和Git实际跟踪集合后再申请作者发布确认。批准针对文件名及SHA256；任何更改后重新生成清单并确认。不要把自动扫描通过当作隐私审查完成。

首次提交使用全新Git历史和项目贡献者身份，不导入任何来源仓库、remote、身份配置或聊天。公开前保留本地；未确认时不创建公开仓库、不上传内容。收到确认后优先gh/Git，认证由用户自己的标准登录流程完成，不索要密码或令牌。

后续优先收集不同题材的小样本失败：非法知情漏检、状态漂移、风格保真与安装缺失。真实长篇、多客户端和多人协作需要独立验证。贡献只接受可再分发的小型虚构样例，不收作者完整私人小说。
